# Campsite Commander

Campsite Commander is an Android application developed in Kotlin to help campers organize and manage their camping gear.

## Features

- Splash screen displayed for 3 seconds on startup
- Add camping gear items
- Store item details using parallel arrays
- View total number of packed items
- Display detailed gear information including:
  - Item Name
  - Category
  - Quantity
  - Notes
- Input validation and error handling
- Easy-to-use interface

## Technologies Used

- Kotlin
- Android Studio
- XML Layouts

## Programming Concepts Demonstrated

- Variables
- Arrays (Parallel Arrays)
- Loops
- Conditional Statements
- Methods
- Intents
- Multiple Activities
- Error Handling
